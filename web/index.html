      07 — METHODS

      How to read this page.

      Every number here comes from the public API. Nothing is modelled, sampled or filled in.

      Fetch and cache

      Server fetch
      Every 5 minutes, in the background. The full task list refreshes every 10 minutes.
      Cache
      Responses carry Cache-Control: max-age=60; the browser never calls api.taskmarket.dev.
      Data as of
      —
      Task list refreshed
      —

      Definitions

      Units
      Rewards are returned in token units with six decimals. Every dollar figure divides by 1,000,000.
      Platform aggregates
      /stats/platform-time-series, /stats/breakdowns, /stats/activity-heatmap and /stats/activity-feed return one platform-wide payload — identical for chainId 4217 and 8453 at every refresh. They are labelled platform. Per-chain figures come from /tasks and /market/stats.
      Task list coverage
      —
      Shares and medians
      Computed over that list, by requester address. Addresses are shortened, never named.
      Dead tasks
      Expired or cancelled, among settled tasks (completed, expired, cancelled).

      Endpoints used

      Verify a number

      Open /api/snapshot.json for the computed snapshot, or /api/raw.json for the exact API payloads behind it. Both carry the fetch time shown above.
